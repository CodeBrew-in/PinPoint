## Local `develop` was about 40 commits behind GitHub
My `App.tsx` still showed the Vite starter page, even though `origin/develop` already had routing, Login and Signup.

Fixed with `git fetch --all` and `git pull origin develop`.
Lesson: always pull `develop` before starting work or judging what "the code" looks like.

## Backend port mismatch: 8001 vs 8000
`docker-compose.yml` mapped the backend to `8001:8000`, but the frontend called `http://localhost:8000`.
Fixed by mapping `8000:8000` (PR #18).

## `ModuleNotFoundError: No module named 'psycopg'`
Same error Tanmay hit (see his daily log): SQLAlchemy 2.1 uses psycopg v3 by default.
Fixed in PR #18 by replacing `psycopg2-binary` with `psycopg[binary]`.

## Docker: `failed to connect to the docker API at npipe:////./pipe/dockerDesktopLinuxEngine`
Docker Desktop wasn't running. Started it and checked with `docker info`.

## Git commits showed the author as "Your Name"
My global git config still had the placeholder name from setup, so commits wouldn't link to my GitHub account.
Then the email got saved with angle brackets (`<sanehbir05@gmail.com>`), which makes a broken author line.
Fixed with:

```shell
git config --global user.name "sanehbir05-dot"
git config --global user.email "sanehbir05@gmail.com"
```

Check with `git config user.name` and `git config user.email` before the first commit on a new machine.

## A 1-line change in `requirements.txt` showed as 44 changed lines
The file was originally committed with Windows line endings (CRLF). Editing it with `sed` wrote LF endings, and with
`core.autocrlf=true` git saw every line as changed. `git diff --ignore-cr-at-eol` showed the real change was only 1 line.
Fixed by keeping the original CRLF endings, so the PR diff shows only the real change.
Lesson: if a diff is much bigger than expected, check line endings first.

## `fatal: pathspec 'backend/app/models/main.py' did not match any files`
I ran `git add` on a file that was already deleted and staged with `git rm`.
Fixed by leaving that path out of `git add`. A file removed with `git rm` is already staged.

## Lint warning: `react/only-export-components`
Our oxlint config warns when a file exports both a React component and something else (like a hook or context).
Hot reload only works reliably on files that export only components.
Fixed by splitting auth into three files: `authContext.ts` (context and types), `AuthProvider.tsx` (component)
and `useAuth.ts` (hook).

Lesson: before fixing something shared, `git fetch` and message each other about what you're fixing.
