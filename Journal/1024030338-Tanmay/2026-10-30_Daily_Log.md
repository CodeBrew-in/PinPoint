# Daily Log - 30 Oct 2026 (Tanmay)

## App opened on a map that no longer existed
After switching the demo data to Patiala, the app still started on the old map id `map_photography_spots`.
The starting map is now taken from the first map in the demo data.

## Signup showed "Welcome back, demo" instead of the name
The name was saved before login finished, so the code did not know the new user's id yet (a stale value).
The name is now saved using the id returned by the signup request.

## "My Maps" was empty for real accounts
The demo maps belonged to a placeholder owner id, so no real user matched them.
The demo maps now count as owned by whoever is logged in, until the backend returns real owners.
