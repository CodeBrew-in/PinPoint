# Daily Log - 29 Oct 2026 (Tanmay)

Short notes on smaller errors. Bigger issues get their own file.

## Map area collapsed to height 0 on desktop
The map workspace used `h-full` inside a flex row whose height came from the flex layout, so the map got no height and looked blank.
Fixed by switching to `md:h-auto` so the flex row stretches the map panel instead.

## CARTO map tiles showed "API KEY REQUIRED"
CARTO's free tiles now return a watermark image instead of a map.
Switched to OpenStreetMap tiles and darkened them with a CSS filter for dark mode.

## Smoke test signup failed with 422
The test e-mail used the `.test` domain, which the e-mail validator rejects as a reserved domain.
Changed the smoke test to a normal-looking domain.

## Smoke test failed in CI with "connection reset"
`docker compose up --wait` returns when containers are running, but the backend was still running migrations.
The smoke test now retries the health check for up to 90 seconds before testing.
