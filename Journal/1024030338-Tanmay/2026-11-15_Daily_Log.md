# Daily Log - 15 Nov 2026 (Tanmay)

## Backend tests failed locally but passed in CI
10 of 73 tests failed because they ran against my local development database, which had leftover data.
After resetting the database (`docker compose down -v`) all 73 passed. Tests should get their own database.

## Script hung on Windows when calling `python3`
On Windows, `python3` can be a Microsoft Store placeholder that waits forever instead of running Python.
The smoke test now creates its throw-away key with `openssl` instead of Python.

## Backend would not start after a security fix
The fix removed the built-in default for `SECRET_KEY`, so the backend now stops at startup if it is missing.
Added a random 64-character `SECRET_KEY` to my `.env`. This is the intended behaviour.
