# Daily Log - 11 Oct 2026 (Tanmay)

Short notes on smaller errors. Bigger issues get their own file.

## `ModuleNotFoundError: No module named 'jwt'`
Dependencies were not installed on the new machine setup.
Fixed by creating `backend/venv` and running `pip install -r requirements.txt`.

## `ModuleNotFoundError: No module named 'psycopg'`
SQLAlchemy 2.1 now uses psycopg v3 for `postgresql://` URLs, but we only had psycopg2.
Fixed by replacing `psycopg2-binary` with `psycopg[binary]` in `requirements.txt`.

## Tests failed with `AttributeError` on every request
In `conftest.py`, `import app.models.user` overwrote the FastAPI `app` variable with the package.
Fixed with `from app.models.user import User` instead.

## Docker: "cannot find the file specified" (dockerDesktopLinuxEngine)
Docker Desktop was not running, so `docker compose` could not reach the engine.
Started Docker Desktop and waited until `docker info` worked.

## Git rebase conflicts with Saneh's PR #18
We both fixed `main.py`, `Dockerfile`, `requirements.txt` and `docker-compose.yml` at the same time.
Kept Saneh's merged version for those files and re-added only my extra changes (`SECRET_KEY`).
