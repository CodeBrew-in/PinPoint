# Week 1 : Git Branch Synchronization Issue

## Error:

Error encountered while pulling the latest changes from `develop`.

```shell
error: The following untracked working tree files would be overwritten by merge:

backend/app/api/auth.py

Please move or remove them before you merge.

Aborting
Relevant Context

I had local changes/files in my working directory while the remote develop branch had changes to the same file.

I tried:

git pull

but Git stopped the merge to prevent my local file from being overwritten.

Key Observation

Git protects untracked local files when a pull would overwrite them.

The problem was not with the remote repository, but with the state of my local working tree.

Solution

I first committed my local work:

git add backend/app/api/auth.py
git commit -m "chore: save local auth work"

Then pulled the latest changes from develop:

git pull

After synchronizing the repository, I created a separate feature branch:

git checkout -b feature/b3
What I Learned

Before pulling or switching branches, I should check:

git status

and make sure my local work is either committed, stashed, or intentionally removed.
